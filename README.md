# ComplianceGuard 🛡️  
An AI-powered policy document checker that leverages **Google Gemini** to detect potential compliance violations in user-uploaded documents.

## 🚀 Overview
**ComplianceGuard** is a simple, streamlined web app built using **Streamlit**. Users can upload policy or regulation documents, and the app uses **Google Gemini** (LLM) to analyze content for possible compliance risks or violations.

Whether you're a compliance analyst, legal professional, or someone working with policy-heavy documents, ComplianceGuard makes it easier to spot potential red flags—fast and with minimal technical effort.

---

## 🔧 Features

- 📄 Upload and analyze PDF or text-based policy documents  
- 🧠 Uses **Google Gemini** for context-aware content review  
- ✅ Flags potential compliance violations based on document interpretation  
- 💻 Built with **Streamlit** for fast, interactive UI  
- 💂️ Clean and modular codebase for easy customization  

---

## 🛠️ Tech Stack

- **Frontend**: Streamlit  
- **Backend**: Python  
- **AI Integration**: Google Gemini API  
- **Other Tools**: Git, GitHub

## ⚙️ How to Run Locally

1. **Clone this repository**  
   ```bash
   git clone https://github.com/SYED-ALI-ml/ComplianceGuard.git
   cd ComplianceGuard
   ```

2. **Install dependencies**  
   *(Use a virtual environment if preferred)*  
   ```bash
   pip install -r requirements.txt
   ```

3. **Set your Gemini API key**  
   Create a `.env` file and add:
   ```
   GEMINI_API_KEY=your_api_key_here
   ```

4. **Run the app**  
   ```bash
   streamlit run app.py
   ```
